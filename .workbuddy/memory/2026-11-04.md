# 2026-11-04

## 首页崩溃修复：adjustSort 里 SourceBean 为 null（v1.11.3）
- 崩溃栈：`DefaultConfig.adjustSort` 第 32 行 `sb.getCategories()` NPE，由 HomeFragment 的 sortResult 观察者触发。
- 根因：切换订阅源后 `ApiConfig.loadConfig()` 会先 clear sourceBeanList 再重建，存在空窗；此时 Hawk 里记录的 `HOME_API` 指向的 key 在新列表里查不到，`getSource()` 返回 null，旧代码直接取 categories。
- 修复：
  - `DefaultConfig.adjustSort`：`sb` 为 null 或 `categories` 为 null 时退化为「全部分栏」，不再 NPE。
  - `ApiConfig` 新增 `getSourceName(key)`：源不存在时返回空串。
  - 把 `getSource(...).getName()` 的链式调用全部换成 `getSourceName(...)`：DetailActivity、CollectAdapter、HistoryAdapter、QuickSearchAdapter、SearchAdapter。
  - `SourceViewModel` 的 getDetail / getSearch / getQuickSearch / getPlay 补 `sourceBean == null` 保护（postValue(null) 后返回），与已有 getSort 的保护一致。
- 未动 `PlayFragment.setData`（sourceKey 失效时播放页会白屏），暂不扩大到播放流程。
- versionCode 95 → 96，versionName 1.11.2 → 1.11.3。产物 `APK/MBox_v1.11.3_release_20261104.apk`。
