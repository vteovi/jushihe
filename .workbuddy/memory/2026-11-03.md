## 播放页 / 直播页大屏宽屏适配（v1.11.0）

参考 `D:/WorkBuddy/TVBoxOS-Mobile` 的平板做法。

### 播放页（详情页详情见 DetailActivity）
- `layout-sw600dp/activity_detail.xml` 顶部改为「左播放器 + 右信息」横向分栏：
  `previewPlayerPlace`(0dp, weight 1.15) + `ll_info_column`(0dp, weight 1，含 tvName/tvSite/iv_private_browsing/actionBtnBar)；
  解析/线路/选集仍放在下方整宽 ScrollView。
- 播放器高度不再写死 400dp，由 `DetailActivity.applyTabletPreviewSize()` 按占位区宽度算 16:9 写回；
  右侧信息栏高度取 `max(播放器高, 230dp)`，保证按钮栏不被挤没。
- **关键**：`previewPlayer` 是根 FrameLayout 的直接子 View（浮层），分栏后必须重新贴到占位上，
  否则会盖住右侧信息。新增 `setupTabletPreview()`（挂 addOnLayoutChangeListener + post 重算）、
  `layoutPreviewOverPlace()`（用 `getLocationInWindow` 做差，不关怀中间套了几层 LoadSir 容器）、
  `onConfigurationChanged()`（清单有 configChanges 不重建，必须手动重算）。
- `toggleFullPreview()` 改成分支：全屏直接铺满；退出全屏先还原 `windowsPreview` 再重算一次（`windowsPreview` 会被
  `layoutPreviewOverPlace` 更新为算出来的 FrameLayout.LayoutParams）。

### 直播页（LiveActivity）
- `layout/activity_live.xml` 重构成可切换的结构：
  `live_root > live_content_row > [live_video_column > (live_video_box > mVideoView + tvRightSettingLayout) + ll_epg] + tvLeftChannnelListLayout`。
  新增 id：`live_content_row`、`live_video_column`、`live_video_box`、`ll_source_switch`。
  `mVideoView` 由 300dp 改 match_parent（原来 300dp 装在 240dp 容器里，底部被裁）。
- `LiveActivity` 新增 `applyLiveLayoutForScreen()` / `applyLiveResponsiveLayout()` / `applyLiveVideoBoxSize()` /
  `applyEpgSourceSwitchLayout()` / `onConfigurationChanged()`：
  - 竖屏：视频列在上（高度 `max(240dp, 短边*9/16)`）、EPG 100dp、列表 weight=1；
  - 横屏：左右分栏，视频列 weight=3（视频区 weight=1 撑满）、EPG 压到 64dp、列表 weight=2；
    EPG 变矮后源切换行从「贴右下角」改成「与右上角图标同一行、位于 ic_cast 左侧」，否则会重叠。
  - 全屏播放期间不处理（`mVideoView.isFullScreen()` 时 return），退回全屏后延时 300ms 重排一次。

## 搜索页平板顶部避让状态栏（v1.11.1）
- 现象：平板横屏下搜索栏与系统状态栏重叠。原因：`layout-sw600dp/activity_fast_search.xml` 根布局 paddingTop 写死 16dp，而平板 autosize 在 sw600dp 时 `getSizeInDp()` 返回屏宽 → 缩放比约 1:1，16dp 小于状态栏 24dp。
- 修复：
  - 平板布局 paddingTop 16dp → 32dp（兜底）。
  - `FastSearchActivity` 新增 `applyTabletStatusBarPadding()`：仅在 `Utils.isTablet()` 时，用 `ViewCompat.setOnApplyWindowInsetsListener` 取 `statusBars()` inset 真实像素，`paddingTop = max(原始 padding, insetTop + 8dp)`；`init()` 与 `onConfigurationChanged()` 均调用。手机布局不动（保持 40dp）。
- versionCode 93 → 94，versionName 1.11.0 → 1.11.1。产物 `APK/MBox_v1.11.1_release_20261103.apk`。
