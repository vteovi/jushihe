# 2026-10-26

## 修复：详情页"外部播放器"崩溃（PlayFragment NPE，Build 1.9.8 / Android 16）
- 崩溃栈：`PlayFragment.playExternal(PlayFragment.java:1677)` → `new java.util.HashMap<>(webHeaderMap)` 时 `webHeaderMap` 为 null → NPE（`HashMap.putMapEntries` 对 null Map 调 size()）。由 `DetailActivity` 详情页点击外部播放器按钮触发。
- 根因：字段 `private Map<String, String> webHeaderMap;`（PlayFragment:1306）声明时未初始化；每次播放结果回调都会先 `webHeaderMap = null;`（1036），只有播放信息里带 `header` 时才会重新赋值（1051）。用户尚未走完带 header 的解析就直接点外部播放器时，它仍是 null，直接 `new HashMap<>(null)` 崩溃。
- 处理：`PlayFragment.playExternal` 内改为空安全拷贝后再传给 `PlayerHelper.runExternalPlayer`：
  `java.util.HashMap<String,String> extHeaders = (webHeaderMap == null) ? new java.util.HashMap<>() : new java.util.HashMap<>(webHeaderMap);`
  注意 `runExternalPlayer(..., HashMap<String,String> headers, long progress)` 的参数类型是 **HashMap**（不是 Map），用 `Map` 声明会编译失败。
- 版本：versionCode 88→89，versionName 1.9.8→1.9.9。
- 验证：`./gradlew :app:compileReleaseJavaWithJavac` → BUILD SUCCESSFUL。

## 修复：详情页预览区"外部播放/打开方式"按钮提示"调用失败，请确认已安装系统播放器"（v1.9.10）
- 现象：详情页预览区全屏按钮旁的"外部播放"按钮（`activity_detail.xml#tvExternalPlay`）点击后弹"调用失败, 请确认已安装系统播放器"。
- 根因：`DetailActivity:226` 固定调用 `playFragment.playExternal(0)`；而 `PlayerHelper.runExternalPlayer` 的 switch **只有 case 10~14**（MX/Reex/Kodi/RemoteTVBox/VLC），没有 `case 0`，`callResult` 恒为 false → 弹失败。`getPlayerName(0)` 又映射成"系统播放器"，所以提示文案就是"确认已安装系统播放器"。
- 正确行为：这个按钮应像"打开一个视频文件"一样，用 `ACTION_VIEW + video/*` 弹出系统"用以下应用打开/选择播放器"面板。播放器内全屏旁那个按钮（`player_vod_control_view.xml#play_external` → `PlayFragment.externalPlay()`）本来就是这么做的，所以它是好的；只有详情页这条走了 `PlayerHelper` 才失败。
- 处理（对齐可用版 `TVBoxOS-Mobile`，其 PlayerHelper 已有 case 0）：
  1. `PlayerHelper.runExternalPlayer` 增加 `case 0` → 新增的 `runSystemPlayer(activity,url,title,subtitle)`：`ACTION_VIEW` + `setDataAndType(uri,"video/*")` + `Intent.createChooser(intent,"选择播放器")`。
  2. `getPlayersExistInfo()` 里 player 0 由固定 `false` 改为用 `PackageManager.queryIntentActivities(video/*)` 判断系统是否存在可处理应用。
  3. 顺手修掉 6 参 `runExternalPlayer` 递归调自己的死循环（改为委托 7 参 `progress=0`）。
  4. 新增 import：`Intent` / `PackageManager` / `Uri` / `App`。
- 版本：versionCode 89→90，versionName 1.9.9→1.9.10。
- 验证：`./gradlew :app:compileReleaseJavaWithJavac` → BUILD SUCCESSFUL。

## 经验
- `PlayerHelper.runExternalPlayer` 的 headers 形参是 `HashMap<String,String>`；传 `Map` 类型变量会编译报错。
- 凡"字段可能为 null 又被直接塞进集合构造器"的地方，传参前做 null 兜底，别指望上游一定赋值。
- 两处"外部播放"按钮实现不同：播放器控制条里的走 `PlayFragment.externalPlay()`（ACTION_VIEW，正常）；详情页预览区的走 `playExternal(0)` → `PlayerHelper`（之前缺 case 0 才失败）。修 UI 问题时注意区分入口。
- `ACTION_VIEW` 无法携带自定义 HTTP 头，需要 Referer/UA 鉴权的直链用系统播放器可能播不了（这是系统限制，非 bug）。
